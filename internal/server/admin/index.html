Reward campaign flow

  1. Load clients — shopping profiles (spend, orders, category) come from the database.
  2. Evaluate segments — each client is tagged (e.g. high_spender, frequent_buyer).
  3. Match rules — enabled rules whose segment matches and whose condition passes fire actions.
  4. Execute actions — award loyalty points and send templated emails.
